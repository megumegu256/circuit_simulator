# Circuit Simulator - 論理回路シミュレータ

視覚的な論理回路シミュレータです。ドラッグ&ドロップで論理ゲートを配置し、配線して回路を構築できます。

## 特徴

### v2.0.0 の実装済み機能
- ✅ 基本論理ゲートのサポート (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- ✅ ドラッグ&ドロップによるゲート配置
- ✅ 視覚的な配線機能
- ✅ 入力信号の設定とトグル
- ✅ シミュレーション実行と結果の視覚的表示
- ✅ 回路の保存/読み込み (JSON形式)
- ✅ 画像エクスポート機能
- ✅ 自動配置整列機能
- ✅ グリッド表示とスナップ機能
- ✅ 設定管理 (config.json)
- ✅ コンポーネントの移動と削除
- ✅ リアルタイムシミュレーション

### v2.0.0 の新機能 ✨
- ✅ **Undo/Redo 機能** - Command パターンによる履歴管理
- ✅ **ズーム機能** - 0.3x～3.0x のズーム (マウスホイール対応)
- ✅ **タブベース回路管理** - 複数の回路を独立して管理
- ✅ **ステップ実行** - シミュレーションを段階的に実行
- ✅ **履歴表示** - シミュレーション結果を詳細表示
- ✅ **ショートカットキーカスタマイズ** - config.json で設定変更可能

### 将来の拡張
- 🔄 量子回路シミュレータの追加 (予定)

## 必要環境

- Python 3.11 以上
- Tkinter (標準ライブラリ)
- Pillow (画像エクスポート用)

## インストール

```bash
# 仮想環境を作成 (推奨)
python -m venv .venv

# 仮想環境を有効化
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 依存関係をインストール
pip install -r requirements.txt
```

## 実行方法

```bash
python main.py
```

## 使い方

### 1. ゲート配置
1. 左側のツールパレットから配置したいゲートを選択
2. キャンバス上の任意の場所をクリックして配置

### 2. 配線
1. ツールパレットの「配線モード」をチェック
2. 出力ピン (赤色) をクリック
3. 入力ピン (緑色) をクリックして接続完了

### 3. 入力設定
- 入力コンポーネント (INPUT) をクリックすると、HIGH (黄色) と LOW (青色) が切り替わります

### 4. シミュレーション実行
1. 「シミュレーション実行」ボタンをクリック
2. 回路全体がシミュレートされ、結果が視覚的に表示されます
   - HIGH信号: 赤色の配線、黄色の入力、緑色の出力
   - LOW信号: 青色の配線、青色の入力、灰色の出力

### 5. コンポーネントの操作
- **移動**: コンポーネントをドラッグ
- **削除**: コンポーネントを右クリック

### 6. 回路の保存と読み込み
- **保存**: メニューバーから「ファイル」→「保存」または「名前を付けて保存」
  - JSON形式で `project/` フォルダに保存されます
- **読み込み**: メニューバーから「ファイル」→「開く」

### 7. 画像エクスポート
- メニューバーから「ファイル」→「画像としてエクスポート」
- PNG形式で保存できます

### 8. 自動整列
- メニューバーから「編集」→「自動整列」
- コンポーネントが自動的にグリッド状に整列されます

## v2.0.0 の新機能の使い方

### 📊 複数回路のタブ管理
- メニューの「ファイル」→「新しいタブ」で新しい回路を作成
- タブを切り替えることで複数の回路を独立して管理できます
- 各タブは独立した Undo/Redo 履歴を持ちます

### ↩️ Undo/Redo 機能
- **元に戻す**: `Ctrl + Z` またはメニュー「編集」→「元に戻す」
- **やり直す**: `Ctrl + Y` またはメニュー「編集」→「やり直す」
- 最大50ステップまでの操作履歴を保持できます
- コンポーネント追加・削除、配線操作、移動などがUndo/Redo対象です

### 🔍 ズーム機能
- **ズームイン**: `Ctrl + +` または マウスホイール上スクロール
- **ズームアウト**: `Ctrl + -` または マウスホイール下スクロール
- **リセット**: メニュー「ビュー」→「100%にリセット」
- ズームレベル: 30% ～ 300% (0.1 単位で調整可能)

### ⏱️ ステップ実行
1. メニューの「シミュレーション」→「ステップ実行」を有効にする
2. 「次のステップ」ボタンで1ステップずつ進める
3. 各ステップでコンポーネントの状態が更新されます

### 📈 シミュレーション履歴表示
1. 「シミュレーション実行」で回路をシミュレート
2. メニューの「シミュレーション」→「履歴表示」をクリック
3. ツリービューで各ステップのコンポーネント出力状態を確認

### ⌨️ ショートカットキーカスタマイズ
1. メニュー「設定」→「ショートカットキー設定」を開く
2. 各アクションのキー入力欄を編集
3. Tkinter の キー表記法に従って設定:
   - `<Control-z>`: Ctrl+Z
   - `<Shift-a>`: Shift+A
   - `<Alt-q>`: Alt+Q
   - `<Button-1>`: マウス左クリック

## 論理ゲート一覧

| ゲート | 記号 | 機能 |
|-------|-----|------|
| AND   | •   | 全ての入力がHIGHの時のみHIGH |
| OR    | ≥1  | いずれかの入力がHIGHならHIGH |
| NOT   | ¬   | 入力を反転 |
| NAND  | •̄   | ANDの出力を反転 |
| NOR   | ≥̄1  | ORの出力を反転 |
| XOR   | =1  | 入力が異なる時にHIGH |
| XNOR  | =̄1  | 入力が同じ時にHIGH |

## アーキテクチャ

### 設計原則
- **モジュール化**: 将来の量子回路シミュレータ追加を考慮した設計
- **拡張性**: 新しいゲートタイプを簡単に追加可能
- **保守性**: クラスベースの設計で可読性と保守性を確保

### 主要クラス

#### Component (基底クラス)
全てのコンポーネント (ゲート) の基底となる抽象クラス

#### LogicGate
論理ゲートの基底クラス (Component を継承)

#### 具体的なゲートクラス
- `ANDGate`, `ORGate`, `NOTGate`, `NANDGate`, `NORGate`, `XORGate`, `XNORGate`
- `InputSource` (入力)
- `OutputDisplay` (出力)

#### Circuit
回路全体を管理するクラス
- コンポーネントの追加/削除
- 配線の管理
- シミュレーション実行 (トポロジカルソート)

#### Wire
配線を表すクラス

#### ConfigManager
設定の読み込み/保存を管理

#### CircuitSimulatorGUI
Tkinterを使用したGUI実装

## トラブルシューティング

### 画像エクスポートができない
Pillowライブラリがインストールされていることを確認してください:
```bash
pip install Pillow
```

### ウィンドウが表示されない
Tkinterが正しくインストールされていることを確認してください。
Pythonが標準でTkinterを含んでいますが、一部のLinuxディストリビューションでは別途インストールが必要です:
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk
```

### 設定ファイルが壊れた
`config.json` を削除すると、次回起動時にデフォルト設定で再作成されます。
